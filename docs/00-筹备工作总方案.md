# 首次业主大会会议筹备工作总方案

## 一、法律依据

依据《吉林省物业管理条例(2024修正)》第二十八条，首次业主大会会议筹备组履行下列职责：

1. 确认并公示业主身份、业主人数以及所拥有的专有部分面积
2. 制定召开首次业主大会会议方案，确定首次业主大会会议召开的时间、地点、形式和内容
3. 拟定业主大会议事规则草案和管理规约草案
4. 确定首次业主大会会议表决规则
5. 制定业主委员会成员候选人产生办法，确定业主委员会成员候选人名单
6. 制定业主委员会选举办法
7. 完成召开首次业主大会会议的其他准备工作

**公示要求**：上述所涉相关事项，应当在首次业主大会会议召开十五日前，以书面形式在物业管理区域内显著位置进行不少于七日的公示。业主对公示内容有异议的，筹备组应当记录并作出答复。

---

## 二、总体时间安排（建议）

假设目标召开日期为 **T 日**，倒推各阶段：

| 阶段 | 时间节点 | 工作内容 | 产出文档 |
|------|----------|----------|----------|
| 第一阶段 | T-45 至 T-35 日 | 确认业主身份、统计面积 | 业主清册、公示公告 |
| 第二阶段 | T-35 至 T-25 日 | 起草议事规则、管理规约 | 草案文本 |
| 第三阶段 | T-25 至 T-20 日 | 确定表决规则、候选人办法 | 表决规则、候选人产生办法 |
| 第四阶段 | T-20 至 T-15 日 | 综合公示（不少于7日） | 公示公告、异议记录 |
| 第五阶段 | T-15 至 T-7 日 | 处理异议、确定候选人名单 | 答复函、候选人名单 |
| 第六阶段 | T-7 至 T 日 | 发送会议通知、准备会务 | 会议通知、选票、议程 |

---

## 三、筹备工作分解

### 职责一：确认并公示业主身份、业主人数及专有部分面积

**工作步骤：**
1. 向物业服务企业或开发商获取房屋清册
2. 向不动产登记中心核实产权信息
3. 编制《业主身份确认清册》（含姓名、房号、面积、联系方式）
4. 统计总人数、总建筑面积、总户数
5. 在小区显著位置公示不少于7日
6. 收集异议并答复

**文档：**
- `01-业主身份确认方案.md`
- `01-附件A-业主清册模板.xlsx`（需自行创建电子表格）
- `01-附件B-业主身份公示模板.md`

---

### 职责二：制定首次业主大会会议方案

**工作步骤：**
1. 确定会议时间（建议周末或节假日）
2. 确定会议地点（小区内公共场地或租赁场地）
3. 确定会议形式（现场会议 / 书面征求意见 / 两者结合）
4. 确定会议议程
5. 编制方案并公示

**文档：**
- `02-首次业主大会会议方案.md`

---

### 职责三：拟定业主大会议事规则草案和管理规约草案

**工作步骤：**
1. 参照住建部《业主大会议事规则（示范文本）》起草
2. 结合本小区实际情况进行调整
3. 征求街道办/社区意见
4. 形成草案并公示

**文档：**
- `03-业主大会议事规则草案.md`
- `04-管理规约草案.md`

---

### 职责四：确定首次业主大会会议表决规则

**工作步骤：**
1. 明确投票权计算方式（按面积+人数双过半）
2. 确定投票方式（现场投票、书面、电子等）
3. 确定计票方式和监票人产生办法
4. 明确通过标准

**文档：**
- `05-首次业主大会会议表决规则.md`

---

### 职责五：制定业主委员会成员候选人产生办法，确定候选人名单

**工作步骤：**
1. 确定业委会成员职数（建议5-11人单数）
2. 制定候选人资格条件
3. 制定候选人报名和推荐程序
4. 组织候选人报名
5. 资格审查
6. 确定并公示候选人名单

**文档：**
- `06-业主委员会候选人产生办法.md`
- `06-附件C-候选人报名表模板.md`

---

### 职责六：制定业主委员会选举办法

**工作步骤：**
1. 确定选举方式（等额/差额）
2. 确定投票程序
3. 确定计票、唱票、监票规则
4. 确定当选标准
5. 明确递补和罢免机制

**文档：**
- `07-业主委员会选举办法.md`

---

### 职责七：其他准备工作

**工作步骤：**
1. 制作选票模板
2. 准备投票箱
3. 安排工作人员分工
4. 准备会议签到表
5. 准备公示公告栏

## 四、重要提示

1. **公示期**：所有方案须在首次业主大会会议召开 **15日前**，以书面形式在物业管理区域内显著位置进行 **不少于7日** 的公示
2. **双过半原则**：业主大会决定事项，应当经专有部分面积占比三分之二以上的业主且人数占比三分之二以上的业主参与表决，并经参与表决专有部分面积过半数的业主且参与表决人数过半数的业主同意
3. **全程留痕**：所有工作应有书面记录，包括会议纪要、公示照片、异议答复等
4. **街道指导**：建议全程接受街道办事处和社区居委会的指导监督
5. **材料归档**：所有筹备材料应妥善保存，作为业主大会档案移交业委会
