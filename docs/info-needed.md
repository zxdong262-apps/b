# 筹备工作所需信息汇总

以下为三个文档模板中所有需要填写的空白字段，按文档和类别整理。筹备组需收集以下信息后方可使用模板。

---

## 一、通用信息（多文档共用）

| 信息项 | 说明 | 涉及文档 |
|--------|------|----------|
| 小区名称 | 如"碧桂园江山名筑" | 全部三个 |
| 坐落位置 | 小区详细地址 | B、综合 |
| 总户数 | 小区全部住宅套数 | B、综合 |
| 总建筑面积 | 小区全部住宅建筑面积（㎡） | B、综合 |
| 已入住户数 | 实际入住的户数 | 综合 |
| 公示期起止日期 | 需连续7日 | B、综合 |
| 异议受理地点 | 如物业办公室、筹备组办公点 | B、综合 |
| 联系人 | 筹备组对接人姓名 | B、综合 |
| 联系电话 | 固定电话或手机号 | B、综合 |
| 受理时间 | 如"工作日 9:00-17:00" | B、综合 |
| 文号 | 如"〔2026〕第01号" | B、综合 |

## 六、信息收集优先级

1. **最先确定**：小区名称、坐落位置、总户数、总建筑面积（几乎全部文档都需要）
2. **筹备组信息**：联系人、联系电话、受理地点、受理时间
3. **时间节点**：公示期起止日期、会议日期时间
4. **业委会设置**：委员人数、副主任人数、候选人人数
5. **候选人资料**：等报名阶段由申请人自行填写
