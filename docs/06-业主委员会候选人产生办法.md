# 业主委员会候选人产生办法

## 一、法律依据

根据《中华人民共和国民法典》、国务院《物业管理条例》、《吉林省物业管理条例》等法律法规，结合本物业管理区域实际情况，制定本办法。

## 三、候选人资格条件

### （一）基本条件

候选人应当同时符合下列条件：

1. 本物业管理区域内的业主（以不动产登记为准）；
2. 具有完全民事行为能力；
3. 遵守国家有关法律法规；
4. 遵守业主大会议事规则、管理规约，模范履行业主义务；
5. 热心公益事业，责任心强，公正廉洁；
6. 具有一定的组织协调能力；
7. 具备必要的工作时间；
8. 本人、配偶及其直系亲属未在本小区物业服务企业任职。

### （二）优先条件

具有以下条件之一的业主，可优先考虑：

1. 中共党员；
2. 具有法律、财务、工程、管理等专业背景；
3. 有物业管理或社区工作经验；
4. 在本小区居住时间较长，熟悉小区情况。

### （三）不得作为候选人的情形

有下列情形之一的，不得作为候选人：

1. 因犯罪被判处刑罚，执行期满未逾5年的；
2. 被列入失信被执行人名单的；
3. 拒不履行业主义务的（如拖欠物业费、专项维修资金等）；
4. 法律法规规定的其他情形。

## 五、候选人权利和义务

### （一）权利

1. 在业主大会上进行自我介绍和竞选演说；
2. 了解选举相关情况；
3. 对选举过程进行监督。

### （二）义务

1. 如实提供个人信息和相关材料；
2. 遵守选举纪律；
3. 接受业主的询问和监督；
4. 不得进行拉票、贿选等违规行为。

---

## 六、退出和递补

1. 候选人在公示期内可以书面申请退出；
2. 候选人资格被取消的，由筹备组按报名顺序递补；
3. 递补后候选人名单重新公示。

---

## 七、违规处理

1. 候选人弄虚作假的，取消其候选人资格；
2. 候选人拉票贿选的，取消其候选人资格，并报有关部门处理；
3. 对取消资格有异议的，可向筹备组申诉。

---

## 八、其他事项

1. 本办法由筹备组负责解释；
2. 本办法经公示后生效；
3. 本办法未尽事宜，依据相关法律法规执行。
