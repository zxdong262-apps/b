# 业主身份确认方案

## 一、工作目的

依据《吉林省物业管理条例(2024修正)》第二十八条第一款，确认并公示业主身份、业主人数以及所拥有的专有部分面积，为首次业主大会的召开奠定基础。

---

## 二、工作原则

1. **依法依规**：严格依据法律法规和不动产登记信息确认业主身份
2. **全面准确**：确保不遗漏、不错登每一位业主信息
3. **公开透明**：确认结果向全体业主公示，接受监督

---

## 三、工作步骤

### 第一步：收集基础资料

| 资料来源 | 获取内容 | 责任人 |
|----------|----------|--------|
| 开发建设单位 | 房屋销售清册、竣工验收资料 | |
| 物业服务企业 | 现有业主信息台账、物业费缴费记录 | |
| 不动产登记中心 | 不动产登记簿信息（需开具介绍信） | |
| 社区/街道 | 已掌握的业主信息 | |

### 第二步：信息核实比对

1. 以不动产登记信息为最终依据
2. 将各方信息进行交叉比对
3. 对信息不一致的，以登记信息为准
4. 存在多个权利人的，确认一名代表为业主大会投票人

### 第三步：编制业主清册

业主清册应包含以下字段：

| 序号 | 姓名 | 身份证号（脱敏） | 房号 | 建筑面积(㎡) | 联系电话 | 备注 |
|------|------|------------------|------|-------------|----------|------|
| 1 | | | | | | |

**统计汇总：**
- 总户数：_____ 户
- 总建筑面积：_____ ㎡
- 已入住户数：_____ 户
- 未售出房屋：_____ 套（开发建设单位为业主）

### 第四步：公示

1. 在小区主要出入口、公告栏等显著位置张贴公示
2. 公示期不少于 **7日**
3. 公示内容包括：业主清册（身份证号脱敏处理）、统计汇总数据
4. 拍照留存公示现场

### 第五步：异议处理

1. 设立异议受理渠道（现场登记、电话、微信等）
2. 业主提出异议的，筹备组应在 **3个工作日** 内核实并答复
3. 异议成立的，更正业主清册
4. 异议不成立的，书面说明理由
5. 所有异议及答复记录归档保存

---

## 四、特殊情况处理

| 情形 | 处理方式 |
|------|----------|
| 业主为法人或其他组织 | 授权代表参加，需提供授权委托书 |
| 业主为无民事行为能力人 | 由法定代理人代为行使权利 |
| 共有产权 | 共有人协商确定一名代表 |
| 业主无法联系 | 公示期满视为无异议，按登记信息确认 |
| 开发商未售出房屋 | 开发建设单位为业主，按一户计算 |
